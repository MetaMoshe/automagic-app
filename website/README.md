# automagic.agency homepage (redesign)

`index.html` is a self-contained, dark-mode homepage for the main
automagic.agency website: services (AI Transformation, AI Strategy,
AI Product Build), the five-phase process, selected work linking to the
portfolio at automagic.onrender.com, approach and ROI measures, the
engagement model and a Book a Call section (Cal.com + hello@automagic.agency).

It is not served by this app (Render serves `public/`). Open the file in a
browser to preview it, or copy it to the website's host to publish.
